Your Roblox game
doesn't have to look blocky

Making a playable Roblox game is no longer hard. The hard part is making one that doesn't look blocky. Here, the AI writes the code for you, and good-looking models become characters that actually move, without you learning modeling, rigging or Luau.

The difference

Same model. The only difference is the skeleton

Roblox's built-in AI can generate very good-looking models, but it cannot generate bones. Without bones a character can only rotate as one lump, like a rock.

This project closes that gap: read the generated model out, add a skeleton, send it back to Roblox. Both are the same model with the same texture; only the right one went through this pipeline.

  • Model and texture: generated by Roblox's built-in AI
  • Skeleton and weights: computed automatically, no manual rigging
  • All 4,291 vertices carry weights, not one was missed
What you don't have to learn

Normally this takes learning three things. Here you need none of them

Not because they don't matter, but because these three can be handed to an AI or a script.

No modeling or rigging

Models come from Roblox's built-in AI; the skeleton and weights are computed by a script.You never open Blender and never need to know what a weight is, and you don't have to pay a third-party service just to make a character move.

No coding

Luau, events, saving, multiplayer: the AI writes all of it. What you can read is the game, not the code, so your job is to check whether the game is right, not whether the code is right.

No Studio interface to learn

Building scenes, placing objects, running tests: the AI does it through Roblox's own tools. You don't need to remember which panel is where, or what each property is called.

What you bring

So what is your job? Three things

Nobody can do these three for you, because each one needs a person who actually wants to play this game.

Say clearly what you want to make

The AI will not start writing the moment it hears "I want a racing game". It asks you five rounds of questions first: who plays it, what the player does over and over, and why they would come back.

Most people's "I want to make an X" is only a picture in their head. There is no gameplay in it yet. Those five rounds are what pull the gameplay out.

Play it yourself

Once it is built you have to go in and play. Whether it is fun, whether it is confusing: only a person can judge that. Measurements never reach it.

In a real project, several key problems were only found by playing. The code reported no errors at all.

Say what feels wrong

You never have to say "this function is wrong". Saying "these two attacks look identical" or "I don't know where to go" is already the spec for the next version.

A real example: the sentence "the left-click attack and the sweep look the same" led to the whole weapon system being redesigned into something better.

It also catches its own mistakes

  • "This can't be done" was overturned by itself. One conclusion in the docs said a certain approach was impossible. It had been there for two weeks. Actually testing it proved it wrong, and it was fixed the same day, with a rerunnable tool added.
  • Silent failures get caught. Most Roblox problems don't raise an error: the screen looks fine while the thing is broken. This method turns "how do I prove I wasn't fooled" into a discipline.
  • No claiming things by mouth. Before saying "it's done", you produce an observable fact, and you prove the check actually fires by feeding it a deliberately broken case.
These are not marketing lines. They are things that really happened in the project record, and were fixed.
Before you start

What you need

Listed honestly here, so you don't find out halfway through the install.

Claude Code

The AI you work with. It needs a paid subscription, and you will type a few commands in a terminal.

Roblox Studio

Free. Install it and you're done; you don't need to learn its interface.

Rojo

Free. A small tool that syncs the AI's code into Studio automatically. Install notes are in the starter kit.

A few things I have to tell you first

  • ★ If you just want a playable game quickly, go use Roblox's official Build or an online generator first. That is much faster and installs nothing. When you notice everything you make looks the same and the characters move like rocks, come back here.
  • The install takes about 30 minutes, and a few steps happen in a terminal. If that alone puts you off, this may not be for you yet.
  • Every trap here was found on Windows. Mac has not been verified at all.
  • Publishing and playing on a tablet have actually been done (the game above is live, and the tablet gyro aiming was tuned on a real device, version by version). But the publishing document inside the starter kit has not been verified step by step, so you may hit things it doesn't cover.
