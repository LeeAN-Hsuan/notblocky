# place/ — Roblox 的場景檔放這裡

## 這個資料夾是空的，這是正常的

**因為場景檔（`.rbxl`）必須由你在 Roblox Studio 裡建立。**

## 怎麼做（Claude 會帶你，這裡只是備忘）

1. 打開 **Roblox Studio**
2. 選 **Baseplate**（最基本的空白場景）
3. **File → Save to File As...**
4. 存到**這個資料夾**，檔名 `game.rbxl`

**就這樣。裡面什麼都不用放。**

---

## 為什麼要這樣（給好奇的人）

這個框架有一條**雙軌**的規矩：

| | 走哪條路 | 誰維護 |
|---|---|---|
| **程式**（`.lua`） | Rojo 自動同步 | **Claude 改磁碟，Studio 自動更新** |
| **模型**（3D 網格、地形） | 存在 `.rbxl` 裡 | **你在 Studio 裡手動存** |

**原因**：3D 模型的幾何是二進位資料，**塞不進文字檔**，所以 Rojo 同步不了它。

⇒ **程式歸 Claude，模型歸你。**

（如果你的遊戲用不到 3D 模型——像範例的 `Hello` 那樣純用方塊——那這個 `.rbxl` 會永遠是空的，
那也完全沒問題。）

---

## ⚠️ 規矩一：只在【停止】狀態下改東西

**要在 Studio 裡放模型、畫地形，一定要在【停止】狀態下做，然後存檔（Ctrl+S）。**

**在遊戲【執行中】（按了 Play）做的任何改動，按停止就會全部消失。**
那是一個沙盒——你可以放心亂玩，但也記得：**它不會被保存。**

---

## ⚠️⚠️ 規矩二：地形跟模型【不一樣】——它不會自己活過 Play

**這條很反直覺，但一定要知道，不然你會白畫一片山。**

- **3D 模型**：你放進場景、存了檔，它就一直在 → ✅ 正常
- **地形**（你用地形筆刷畫的山、峽谷、水池）：**你存了檔，但一按 Play 就消失** → ❌

**為什麼**：Roblox 一個場景**只有一個地形**（它是全域的，不屬於任何一個遊戲）。
如果讓地形常駐，你做**第二個**遊戲時，**第一個遊戲的山會蓋在新遊戲的頭上**。
所以這個框架在每次啟動遊戲前，都會先把地形清乾淨。

**⇒ 你畫的地形要留住，得多做一步（跟 Claude 說一聲就好）：**

> **「我畫好地形了，幫我存成素材」**

Claude 會把它擷取成一份素材（`SceneTerrain.capture`），然後叫你按 **Ctrl+S**。
之後遊戲每次啟動就會自己把它貼回來。

**（另一條路更省事：直接跟 Claude 說你想要什麼樣的地形——
「一片有峽谷和岩柱的岩石荒原」——它可以用程式生出來，你連筆刷都不用碰。）**
