# PUBLISH — 怎麼讓小孩在平板上玩到

> **這份文件回答一個必然會出現的問題：**
> **「遊戲做好了，怎麼讓我兒子在他的平板上玩到？」**

> ⚠️⚠️ **誠實聲明：這一份的內容來自 Roblox 官方文件，但【尚未實際跑過一遍】。**
> **步驟名稱、選單位置可能跟你眼前的 Studio 有出入（Roblox 的 UI 改得很勤）。**
> **如果你（Claude）跟著使用者走這一段，發現實際流程跟這裡寫的不一樣 ——**
> **★ 請當場把正確的流程回寫進這份文件。** 這份清單就是這樣長出來的。

---

## 先講最重要的一件事：**不要選 Public**

Roblox 的權限有三種：

| 設定 | 誰能玩 | 適用 |
|---|---|---|
| **Private** | **只有你自己**（創作者） | 預設值。做到一半時就維持這個 |
| **Friends** | **你的 Roblox 好友** | ★★ **給家人玩，選這個** |
| **Public** | **Roblox 上的所有人** | ❌ 不要。你只是想給小孩玩，不是要開一個公開遊戲 |

**★ 新遊戲預設就是 Private。** 你要主動去改成 Friends，小孩才玩得到。

## 完整流程

### ★★★★ Step -1 — 發布【之前】：先確認你正要上傳的，是【最新的】腳本

**★ 這一步最容易跳過，而且跳過的代價最大 —— 你會把【舊版本】發布給小孩，而每個綠燈都是綠的。**

**機制**（詳見 `docs/GOTCHAS.md` §1.5b）：
Rojo 把腳本寫進 Studio 的記憶體；使用者按 **`Ctrl+S`** 時，
**那些腳本就被一起烤進 `.rbxl` 檔了**。而這個框架**到處叫他按 `Ctrl+S`**（存模型、存地形）。

**於是**：

```
第 5 天：他開 game.rbxl → 忘了跑 rojo serve → 也沒按 Connect
→ 你改了一整個下午的程式碼（磁碟上）
→ 他按 File → Publish to Roblox
→ ★ 上傳的是【第 4 天烤進檔案的舊腳本】
→ 小孩在平板上打開 → 遊戲【會動】✅（所以「小孩玩到了」這一格照樣打勾）
→ 但那是舊版。他說「我明明改好了啊」，而你找不到任何一個紅燈。
```

**⇒ 按 Publish 之前，跑一次「開工儀式」的三項檢查：**

| # | 檢查 | 綠燈長什麼樣 |
|---|---|---|
| 1 | `rojo serve` 在跑嗎？ | 終端機印著 `Rojo server listening` |
| 2 | Rojo 外掛顯示 **Connected** 嗎？ | 請使用者看一眼面板（★ 只有他看得到） |
| 3 | **★ 種一個隨機記號，在 Studio 裡找得到嗎？** | `GOTCHAS.md` §1.5b（★ **要在 Edit 模式下驗**） |

**三項全綠，才按 Publish。**

---

### ★★★ Step 0 — 發布【之前】：先確認這個遊戲在平板上真的動得了

**★ 這一步不能跳。跳過它，前面所有的努力會在小孩打開遊戲的那一刻歸零。**

**問題**：Roblox 免費送你**搖桿**和**跳躍鈕**。
但**你自己綁的每一顆鍵**（飛、射擊、互動、切換……）—— **平板上一顆按鈕都不會出現。**

**而你在電腦上開發、用鍵盤測試，每一項都會是綠的。**

**⇒ 自己驗，不要等小孩：**

> **Studio → `Test` 分頁 → `Device` → 選 `iPad` → 按 Play → 用滑鼠點點看。**
>
> - 左下角有**搖桿**嗎？（角色走得動嗎？）
> - **你綁的每一個動作，畫面上都有一顆按鈕嗎？**
> - 點得動嗎？做得出你要它做的事嗎？

**任何一個動作在這裡點不到 → 現在就回去修**（`docs/GOTCHAS.md` §6.6），**不要發布。**

**（Roblox 免費送的只有「移動」和「跳」。其他全部要你自己長按鈕出來。）**

---

### 前置：小孩要有一個 Roblox 帳號，而且要跟你**互加好友**

**「Friends」指的是 Roblox 的好友關係**，不是「你認識的人」。

1. 小孩要有自己的 Roblox 帳號（在 https://www.roblox.com/ 註冊，免費）
2. **你和他要互相加為好友**（在 Roblox 網站或 app 裡搜尋對方的使用者名稱 → 加好友 → 對方接受）

⚠️ **未成年帳號可能有社交限制**（例如需要家長同意才能加好友、或聊天功能受限）。
如果加不了好友，去小孩帳號的 **設定 → 家長監護（Parental Controls）** 看看。

---

### Step 1 — 從 Studio 發布

**Studio → File → Publish to Roblox As...**（第一次發布用這個）

- **Name**：遊戲名字（★ 讓小孩取，這是他的遊戲）
- **Description**：隨便寫
- 按 **Create**

⇒ 這會在你的 Roblox 帳號底下建立一個新的「Experience」（遊戲）。

**★ 之後每次改了東西要更新，用 `File → Publish to Roblox`（不帶 As...）——它會覆蓋同一個遊戲。**

---

### Step 2 — 開權限：Private → Friends

**Studio → Home 分頁 → Game Settings → Permissions**

把 **Playability** 從 `Private` 改成 **`Friends`**。

⇒ **這一步做完，你的 Roblox 好友（包含小孩）就能玩到了。**

---

### Step 3 — 開啟平板支援

**同樣在 Game Settings 裡**（通常在 `Basic Info` 或 `Devices` 分頁）：

**勾選 `Tablet`**（想在手機上玩就再勾 `Phone`）。

⚠️ **不勾的話，遊戲不會出現在平板上**——小孩會說「我找不到」，而你會以為是權限的問題。

---

### Step 4 — 小孩怎麼在平板上找到它

在平板的 **Roblox app** 裡：

- **方法 A**：進你的個人檔案（搜尋你的使用者名稱）→ 看你的 **Creations / Experiences**
- **方法 B**：你把遊戲的連結傳給他（在 Roblox 網站上打開遊戲頁面，複製網址）
- **方法 C**：如果你正在玩，他可以從好友列表 **Join**（加入你的遊戲）

## ★ 幾件現在就該想清楚的事

### 1. 存檔（DataStore）需要「發布」才能用

**如果遊戲要記住進度**（分數、解鎖、上次玩到哪），就要用 Roblox 的 `DataStore`。

**而 `DataStore` 在【沒有發布過】的 place 上根本不能用**：

```
錯誤訊息：You must publish this place to the web to access DataStore.
```

**還要在 Studio 裡開一個開關**：
**Game Settings → Security → Enable Studio Access to API Services**

⇒ **想做「小孩下次進來還記得上次拿了幾個星星」，必須先發布。**

★ **這也是一個判斷訊號**：
**當使用者開始說「要記住進度」，就代表這已經不是實驗，是一個他想持續玩的遊戲了。**

### 2. 更新遊戲，小孩不必重新下載

改完程式 → `File → Publish to Roblox` → 小孩**下次進遊戲時就是新版**。

（Roblox 的遊戲是伺服器端的，不像 App 要重新安裝。）

### 3. 免費，但有配額

發布遊戲**不用錢**。但有些東西要 Robux：
- 上傳自訂音效、圖片（有免費額度）
- 賣道具、做 Game Pass

**單純做一個給家人玩的遊戲，完全不會花到錢。**

## ⚠️ 隱私與安全（★ 給小孩玩，這一段別跳過）

**你正在把一個遊戲放到 Roblox 的伺服器上，而小孩會用他的帳號登入去玩。**

**選 `Friends` 而不是 `Public`，就是最重要的那道防線** —— 它確保：

- 陌生人**看不到**這個遊戲、**進不來**
- 遊戲裡不會有你不認識的人

**其他該注意的：**

- ⚠️ **不要在遊戲裡放真實姓名、學校、住址、照片。**
  「Friends」擋得住陌生人，但擋不住「你把連結轉貼到別的地方」。
- ⚠️ **如果之後想開 Public**（例如小孩想給同學玩）：Roblox 會做內容審核，
  而且**任何人都能進來**。那是完全不同的決定，**要跟小孩一起想清楚再做**。
- ✅ **小孩帳號建議開啟家長監護**（Parental Controls）：可以限制聊天、限制誰能加好友。
