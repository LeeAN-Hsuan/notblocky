# rigging — 做一隻「會拍翅膀」的生物

> **這是選配。** 不碰它，框架照樣能用（只是你的生物只能整塊移動，不能彎折）。

---

## 這是在解決什麼問題

Roblox 官方的 AI（`generate_mesh`）**造型很強**，一句話就能生出一條漂亮的龍。

**但它生的模型【沒有骨頭】。**

沒有骨頭 ⇒ 你只能把整塊模型當硬板旋轉、移動、縮放。

**做不到**：翅膀拍動時根部漂亮地黏在身上、四肢自然彎曲、尾巴柔軟擺動。

**症狀長這樣**：翅膀靜止時完美貼合身體，**一拍動就整片飛出去。**

> **這不是程式寫不好，是模型裡沒有骨頭。**
> 我們在做這個框架時，花了整整四輪去修一個「素材裡根本不存在的東西」。

**有骨頭，網格才會【真的彎】。** 而綁骨架是 Blender 的地盤 —— 這支工具就是幹這個的。

---

## 你需要什麼

| | |
|---|---|
| **Blender** | **免費**。到 [blender.org](https://www.blender.org/download/) 下載安裝，一路下一步就好 |
| **Python** | 你電腦上大概已經有了。沒有的話到 [python.org](https://www.python.org/downloads/) 下載 |

**★ 你不需要學會用 Blender。** 你不會打開它的介面。這支工具是在背景跑它。

---

## 三步驟

### ① 改一個 JSON 檔，描述你要的生物

打開 `creature.rig.json`，它長這樣（每一行都有中文說明）：

```json
{
  "name": "flyer",
  "body": { "w": 26, "d": 16, "h": 60 },
  "limbs": [
    { "name": "WingR", "attach": [0.35, 0, 0.78], "dir": [1, 0, 0], "segments": 3, "length": 90, ... },
    { "name": "WingL", "attach": [-0.35, 0, 0.78], "dir": [-1, 0, 0], "segments": 3, "length": 90, ... },
    { "name": "Tail",  "attach": [0, 0, 0.15], "dir": [0, 1, -0.3], "segments": 3, "length": 55, ... }
  ]
}
```

**一隻肢體 = 一條骨鏈。** 想加四條腿？就多加四個 `limbs`，`dir` 設成往下 `[0, 0, -1]`。

**`segments` = 這隻肢體分幾節 = 幾根骨頭。** 節數越多，動作能做得越細（翅膀 3 節就很像鳥了）。

### ② 跑它

```bash
blender --background --python build_rig.py -- creature.rig.json out/
```

（Windows 上 Blender 通常在 `C:\Program Files\Blender Foundation\Blender X.X\blender.exe`，
 要用完整路徑；或把它加進 PATH。）

會產出 `out/flyer.glb`。

### ③ ★★★ 驗它（不要跳過這步）

```bash
python rig_check.py out/flyer.glb
```

**為什麼一定要跑**：Blender 說「匯出完成」**不代表 glb 裡面真的有骨架**。
匯出一樣成功、檔案一樣產生、Blender 一樣不報錯 —— 但你可能拿到**一塊死網格**，
然後一路以為自己有骨架，直到匯進 Roblox、翅膀怎麼都拍不動。

看到 **`✅ 這個 glb 真的帶骨架`** 才往下走。

---

## 匯進 Roblox

1. Studio → **Avatar 頁籤 → 3D Importer**（或 `File → Import 3D`）
2. 選 `out/flyer.glb`，設定保持預設
3. **匯完只按一次**（★ 按兩次會匯進兩份，長得一模一樣疊在一起，很難發現 —— 我們踩過）
4. **記得 Ctrl+S 存檔** —— 3D 模型不走 Rojo，不存檔關掉 Studio 就沒了

---

## 讓它動起來（給 AI 看的部分，你可以直接把這段貼給 Claude）

```lua
-- 骨頭是 Bone 實例，Transform 是可寫的 CFrame（相對於父骨頭）
bone.Transform = CFrame.Angles(math.rad(20), 0, 0)
```

- **不需要動畫檔**，純程式就能驅動
- **骨頭階層自動生效**：動 `WingR_1`，它底下的 `WingR_2` / `WingR_3` 會跟著走
- ⚠️ **`Bone.Transform` 不會從伺服器同步到客戶端** ⇒ **骨架動畫必須寫在客戶端**
  （細節見 `../docs/GOTCHAS.md` §7.3。這條不知道的話，會做出「只有你看得到的動畫」）

## 老實說：這個工具的限制

**造型會比較樸素**（低多邊形、幾何感）。官方 AI 生的龍漂亮得多。

> ### ⚠️ 這裡原本寫「你不能兩者兼得——官方 AI 生的模型出不來」。**那是錯的。**
>
> 2026-07-27 實測：官方生的網格**出得來**（`EditableMesh` 讀幾何 + `HttpService` 送出），
> 綁完骨架匯回 Roblox 之後**真的會彎**。做法見 **`mesh-export/README.md`**。
> 那句話一直是推論、沒人測過，卻被當成結論寫進三份文件。

所以你要選：

| 你要什麼 | 用哪個 |
|---|---|
| 漂亮造型，不需要細緻動作（整隻飛、整隻轉） | **官方 `generate_mesh`**（免費、秒出、造型完勝） |
| 漂亮造型 + 關節會動（接縫可接受） | 官方 `generate_mesh` 給 **`partNames` 拆件** + `Motor6D`（寫 `C0`） |
| **漂亮造型 + 真的會彎**（skinned） | **`mesh-export/`**（多一段管線，但造型是官方的） |
| **精確規格的幾何**（孔距、對稱、可量產） | **這支工具**（造型樸素，但規格說了算） |

★ **建議仍然是先用官方的把遊戲做起來、確認好玩了**，真的需要彎折再回頭處理。

## ⚠️ 綁骨架時最容易靜默出錯的兩件事

1. **Blender 的自動權重（`ARMATURE_AUTO`）會留下沒有權重的頂點，而且不報錯。**
   實測：1,016 個頂點裡有 **22 個** 權重總和是 0。
   症狀是「靜止時完全正常，一動就有幾個點釘在原地」。
2. **決定論權重不能用「全身最近的 N 根骨頭」。**
   人形的左手腕離右手腕很近，會被綁到**另一隻手**上——
   而骨頭數、影響數、孤兒頂點檢查**全部都會過**。
   ⇒ 候選骨頭要限定在**自己這條骨鏈 + 父骨**。

**★ 兩件事的共同修法：綁完之後自己把權重讀回來數一次，並且用一個蓄意綁錯的檔案
（陽性對照）證明你的檢查器在有問題時真的會叫。**
